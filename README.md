# Note Fluid MIDI Visualization Player

**Note Fluid MIDI Visualization Player** 是一个功能简单、易用、免费的MIDI可视化应用，在WPF应用框架上开发。

**Note Fluid MIDI Visualization Player** is a simple, easy-to-use, and free MIDI visualization application built on the WPF application framework.

---

## 功能 | Features

1. 从文档的特定文件夹中读取所有MIDI文件 ✅
   
   Read all MIDI files from a specific folder in the document directory ✅

2. 播放MIDI文件 ✅
   
   Play MIDI files ✅

3. 根据音符实时生成可视化的钢琴卷帘瀑布流动画 (正在开发中)
   
   Generate real-time piano roll waterfall animation based on notes (Under Development)

4. 多语言本地化支持 (正在开发中)
   
   Multi-language localization support (Under Development)

---

## 如何使用 | How to Use

1. 在主菜单打开"设置"页面，点击"打开文件夹"

   Open the "Settings" page from the main menu and click "Open Folder".

2. 将你需要播放的.mid文件移动到当前文件夹中

   Move the `.mid` files you want to play into the current folder.

3. 在主菜单打开"演奏音乐"页面，可以发现已读取的所有MIDI文件（如果在运行中存入文件，需要重启应用）

   Open the "Play Music" page from the main menu to discover all the MIDI files that have been loaded (if you add files while the application is running, you need to restart the application).

4. 选中文件，点击继续按钮即可播放

   Select a file and click the "Continue" button to start playback.
